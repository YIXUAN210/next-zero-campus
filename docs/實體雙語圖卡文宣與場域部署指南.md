# 實體雙語圖卡文宣與場域部署指南 (Agent 4 交付物)

---

## 壹、 雙語圖卡設計規範與文案

本專案規劃 **3 款防水雙語圖卡**，張貼於校園三大高耗能與生活熱點，引導師生透過 QR Code 進入 GitHub Pages 參與任務。

### 圖卡 1：冷氣空調節能（任務 A）
- **張貼點位**：各系所大樓教室、電腦教室及研究室之冷氣控制面板旁。
- **中文標題**：隨手調高 1°C，為校園降溫！
- **英文標題**：*Set AC to 26–28°C for a Greener Campus*
- **數據佐證**：💡 教室冷氣每調高 1°C，每天可省下約 **2.5 度電**。
- **行動呼籲**：掃描下方 QR Code 拍照打卡 ➔ 解鎖全校永續拼圖！

---

### 圖卡 2：低碳生活與減塑（任務 B）
- **張貼點位**：學生餐廳點餐區、回收台、各樓層飲水機旁。
- **中文標題**：自備環保餐具，減塑減碳愛地球！
- **英文標題**：*Bring Your Own Utensils & Bottles, Cut Carbon Footprint*
- **數據佐證**：💡 每次自備餐具與環保杯，平均減少約 **0.15 kg** 碳排放。
- **行動呼籲**：掃描下方 QR Code 拍照打卡 ➔ 解鎖全校永續拼圖！

---

### 圖卡 3：走樓梯與公用巡檢（任務 B & C）
- **張貼點位**：主要教學大樓電梯等待區、樓梯口。
- **中文標題**：少搭三層電梯，巡檢節能同行！
- **英文標題**：*Take the Stairs & Report Energy Waste on Campus*
- **數據佐證**：💡 多走樓梯健康又節能；發現無人設備異常耗能請拍照通報！
- **行動呼籲**：掃描下方 QR Code 拍照通報 ➔ 解鎖全校永續拼圖！

## 貳、 實體圖卡印刷規格建議
1. **尺寸規格**：A5（148 × 210 mm）或 A6（105 × 148 mm）。
2. **材質建議**：250P 銅西卡 + 雙面上霧膜 / 亮膜（防潑水、耐磨損、抗日曬）。
3. **QR Code 規格**：建議印刷尺寸不小於 $3.5 \times 3.5\text{ cm}$，黑白對比分明，邊緣留白 $5\text{ mm}$ 以利手機快速辨識。
