# 實體雙語圖卡文宣與場域部署指南 (五大任務完整版)

---

## 壹、 五大雙語圖卡設計規範與文案

本專案規劃 **5 款防水雙語圖卡**，張貼於校園五大生活與節能熱點，引導師生透過 QR Code 進入 GitHub Pages 參與任務。

---

### 圖卡 1：教室空調節能（任務 1）
- **張貼點位**：各系所大樓教室、階梯教室、電腦教室及研究室之冷氣控制面板旁。
- **中文標題**：教室空調設為 26 度，隨手關閉電源！
- **英文標題**：*Set Classroom AC to 26°C & Turn Off When Leaving*
- **執行方式**：冷氣設定 26–28°C 搭配電扇，無人使用時隨手關閉冷氣與電燈。
- **數據佐證**：💡 教室冷氣每調高 1°C，每天可省下約 **2.5 度電**。
- **行動呼籲**：掃描下方 QR Code 拍照打卡 ➔ 解鎖全校永續拼圖！

### 圖卡 2：短程爬梯行動（任務 2）
- **張貼點位**：主要教學大樓電梯等待區、各樓層樓梯轉角口。
- **中文標題**：短程爬梯代替搭電梯，健康節能同行！
- **英文標題**：*Take the Stairs Instead of the Elevator for Short Distances*
- **執行方式**：校內移動 3 層樓以內改走樓梯，減少電梯頻繁啟動之瞬間高能耗。
- **數據佐證**：💡 少搭一層電梯約省電 **0.05 度**，多走樓梯健康又環保。
- **行動呼籲**：掃描下方 QR Code 拍照打卡 ➔ 解鎖全校永續拼圖！

### 圖卡 3：拔除待機電力（任務 3）
- **張貼點位**：學生宿舍門口、實驗室插座旁、研究室門口。
- **中文標題**：出門拔除待機電力，切斷隱形耗能！
- **英文標題**：*Unplug Standby Devices & Switch Off Power Strips When Leaving*
- **執行方式**：離開宿舍或研究室時，關閉延長線總電源開關或拔除閒置電器插頭。
- **數據佐證**：💡 家電待機電力約佔家庭與宿舍總用電 **7%～10%**。

### 圖卡 4：自備環保容器（任務 4）
- **張貼點位**：學生餐廳點餐區、回收台、校內便利超商與飲水機旁。

## 貳、 實體圖卡印刷規格建議
1. **尺寸規格**：A5（148 × 210 mm）或 A6（105 × 148 mm）。
2. **材質建議**：250P 銅西卡 + 雙面上霧膜 / 亮膜（防潑水、耐磨損、抗日曬）。
3. **QR Code 規格**：建議印刷尺寸不小於 $3.5 \times 3.5\text{ cm}$，黑白對比分明，邊緣留白 $5\text{ mm}$ 以利手機相機快速對焦辨識。
